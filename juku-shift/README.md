# 個別指導塾 シフト管理(Google スプレッドシート + Apps Script)

PCで使うWebアプリ。アルバイトが入れる時間に○をつけ、保護者が科目・時間帯・先生の希望を出し、管理者が候補を見ながら授業を確定する。
`docs/` にある「くすりログ」とは**別のアプリ**。データも混ぜない。

## 仕組み

- データ置き場: Googleスプレッドシート(シート `Users` `Sessions` `Avail` `Requests` `Lessons` `Settings` は初回アクセスで自動作成)
- サーバー処理: `Code.gs`(スプレッドシートにバインドしたApps Script)
- 画面: `Index.html`(Apps Scriptが配信。ライブラリなし、外部通信なし)
- ログイン: 1人ずつメール+パスワード。パスワードはソルト付きでハッシュ化して保存、5回失敗で10分ロック、ログインは7日で失効
- 権限: アルバイトは自分の空きと自分の授業だけ。保護者は自分の希望と自分の授業だけ。全員のデータは管理者だけが見られる(サーバー側で判定)

## セットアップ(最初の1回)

1. Googleドライブで新しいスプレッドシートを作る(名前は自由。**共有設定は自分だけのまま**にする)
2. メニューの「拡張機能 → Apps Script」を開く
3. `Code.gs` の中身を貼り付ける。左の「＋ → HTML」で `Index` というHTMLファイルを作り、`Index.html` の中身を貼り付ける
4. 保存してスプレッドシートを開き直す → メニューに「シフト管理」が出る → 「管理者アカウントを作成」でメール・名前・パスワードを入れる
5. Apps Scriptの「デプロイ → 新しいデプロイ → ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**(ログインはこのアプリのメール+パスワードで行う)
6. 出てきたURLを管理者・アルバイト・保護者に共有する。コードを直したら「デプロイを管理 → 新バージョン」で更新する

## 使い方

1. 管理者: 「設定」で科目・授業の時間帯・その月の締切を決める → 「ユーザー」でアルバイトと生徒を登録(最初のパスワードを渡す。各自「パスワード変更」で変更)
2. アルバイト: 月ごとに入れる時間(1時間単位)に○
3. 保護者: 月ごとに、日付・科目・入りたい時間帯・授業の長さ・教わりたい先生を、複数件出す
4. 管理者: 「マッチング」で生徒の名前をクリック → 希望ごとに、科目・学年が合い、空きがあり、授業が重ならない先生を候補表示 → 「この候補で確定」(時間・先生は手で直せる)
5. 「時間割」で確認、CSV出力・印刷。確定した授業は、アルバイトと保護者の画面にも出る

候補の並び順: 希望の先生 → 週の上限を超えない先生 → その週のコマ数が少ない先生。上限を超える確定はできるが警告が出る。

## 手元で確認する

```
node juku-shift/dev/api-test.js      # サーバー処理のテスト
node juku-shift/dev/server.js        # http://localhost:8791 (メモリ上のダミーデータ)
node juku-shift/dev/e2e.js           # 画面の通しテスト(上のサーバーが起動中で、起動直後の状態が前提)
```
開発用サーバーのログイン例(ダミー): `admin@example.com` / `admin-pass-1`、先生 `ta@example.com` / `teacher-pass-1`、保護者 `pa@example.com` / `parent-pass-1`

## 守ること

- 生徒名・先生名・メールなどの実データをコード・ドキュメント・コミットに書かない(ダミーだけ)
- スプレッドシートを他人に共有しない(共有すると全員分のデータとハッシュが見える)
- 外部サービス・外部スクリプトを足さない
